# First Agent

After setting up Worker Agent, try running your first autonomous agent:

## 1. Start the stack

```bash
npm run dev:all
```

## 2. Access the Workspace

Navigate to [http://localhost:5173](http://localhost:5173) and sign in.

## 3. Create an Agent

From the **Agents** workspace:

1. Click "Create Agent"
2. Select a model (e.g., `gpt-4o`)
3. Configure the agent's purpose and capabilities
4. Save

## 4. Run the Agent

1. Open the agent's detail page
2. Enter a task prompt
3. Click "Execute"
4. Watch real-time execution in the timeline
