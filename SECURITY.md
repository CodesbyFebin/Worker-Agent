# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main (RC branch) | ✅ |
| < RC-1 | ❌ |

## Reporting a Vulnerability

Report privately via **GitHub Security Advisories** (Security → "Report a vulnerability")
or security@workeragent.cloud. Do NOT open public issues for security findings.

**Include:** description, affected component, reproduction steps, impact assessment.

## What to Expect

- Acknowledgement within **48 hours**, triage within **7 days**.
- Coordinated disclosure: we patch, then you publish (90-day default window).

## Safe Harbor

Research conducted in good faith against this repository under this policy is
authorized. We will not pursue legal action for accidental, good-faith violations.

## Out of Scope

- Social engineering, physical attacks, DoS against production hosts.
- Findings requiring secrets we do not control (third-party provider leaks).

## Thank You

Verified reporters are credited (with permission) in our release notes.
